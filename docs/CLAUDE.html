Publications Data Format

Publications are stored in publications.yaml. Each entry has:

- title: "Paper title"
  author: Last, F., <strong>Boyer, C.</strong>, ...  # Bold marks Chris
  date: '2025'                         # Year string (NOTE: EJS adds +1, see below)
  categories:
  - Pre-print | Methodological | Randomized Trials | Applied/Collaborative | Dissertation
  subtitle: Journal Name                # Journal/venue
  volume: 36
  issue: 3
  pages: 363-373
  path: https://doi.org/...            # Primary link
  doi: https://doi.org/...             # DOI URL
  url_preprint: https://...            # Optional links
  url_repo: https://...
  url_pdf: files/...
  url_slides: ...
  url_pap: ...                         # Pre-analysis plan

Important quirk: The EJS template (ejs/citation.ejs) adds +1 to the year extracted from the date field due to a JavaScript Date timezone issue. This means the date field in publications.yaml should be set to one year before the actual publication year (e.g., date: '2025' renders as “2026”). This is a workaround — be aware of it when adding new entries.

Publication Categories

  • Pre-print: Working papers and preprints (arXiv, medRxiv, etc.)
  • Methodological: Methods-focused peer-reviewed papers
  • Randomized Trials: Papers reporting RCT results
  • Applied/Collaborative: Collaborative applied research
  • Dissertation: Doctoral dissertation

Talks Data Format

Talks are in talks.yaml:

- title: "Talk title"
  description: |
    Venue/conference short description
  author:
    - name: Christopher B. Boyer
  date: 'YYYY-MM-DD'
  subtitle: Full venue description
  image: talks/YYYY-MM-DD/snapshot.png
  path: talks/YYYY-MM-DD/slides.pdf

Each talk directory contains a snapshot.png (thumbnail) and slides.pdf.

Common Tasks

Render the site locally

quarto render

Preview the site locally

quarto preview

Add a new blog post

  1. Create directory: posts/YYYY-MM-DD-slug/
  2. Create index.qmd with front matter (title, date, categories, description)
  3. Write content with code chunks if needed
  4. Run quarto render (or quarto preview)

Add a new publication

  1. Add entry to publications.yaml
  2. Set date to one year before actual year (due to EJS +1 quirk)
  3. Choose category: Pre-print, Methodological, Randomized Trials, Applied/Collaborative, Dissertation
  4. Bold the author name with <strong>Boyer, C.</strong>

Add a new talk

  1. Create directory: talks/YYYY-MM-DD/
  2. Add slides.pdf and snapshot.png
  3. Add entry to talks.yaml
